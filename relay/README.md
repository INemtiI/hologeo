# Ретранслятор «Общего экрана»

Крошечный сервер без зависимостей (чистый Node 18+), который делает функцию
«Общий экран» независимой от внешних сервисов: ведущий публикует сцену комнаты
обычным HTTP-запросом, дисплеи забирают её длинным опросом (long-poll).
Никаких WebSocket и сторонних брокеров — проходит через любые прокси.

## Запуск

```
node relay/server.js            # порт 8081
PORT=9000 node relay/server.js  # другой порт
```

## Подключение к сайту

Добавьте к адресу сайта параметр `?relay=` с адресом ретранслятора, например:

```
https://ваш-сайт/?relay=http://192.168.1.10:8081
```

Ссылка/QR созданной комнаты автоматически передают этот адрес дисплеям.

Если сайт открыт из предпросмотра вида `8080-….e2b.app`, ретранслятор на порту
`8081-….e2b.app` подхватывается сам — параметр не нужен.

## Запасной канал

Если ретранслятор не задан или недоступен, сайт пробует публичные MQTT-брокеры
(`broker.emqx.io`, затем `broker.hivemq.com`). Свой брокер: `?broker=wss://…`.

## Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/ping` | проверка доступности |
| POST | `/room/:код/state` | ведущий публикует сцену (тело — JSON) |
| GET | `/room/:код/state?after=<ts>` | дисплей ждёт новую сцену (до ~1 с) |
| POST | `/room/:код/viewers/:id` | присутствие дисплея `{online: true/false}` |
| GET | `/room/:код/viewers` | список живых дисплеев |

Комнаты без активности живут 10 минут, дисплей без сигналов забывается через 25 с.
